# kugorang apps and games

This is the static portfolio at <https://kugorang.github.io/>. GitHub Pages
publishes the root of `main`; no build step or external assets are required.

| Page | Content source |
| --- | --- |
| `/` | Short introductions to Fillday, Moonjunk Workshop, Facet Sudoku, and Oseonro |
| `/Facet/` | Facet Sudoku introduction and support |
| `/Oseonro/` | Oseonro concept and development status |

Fillday's detailed homepage and legal pages are generated from the Fillday
repository and published at <https://fillday.kugora.ng/>. Moonjunk Workshop's
public introduction, support, and legal pages are published from the separate
`kugorang/moonjunk-pages` repository at <https://moonjunk.kugora.ng/>. Keep
those product pages with their owning repositories. The legacy `/Fillday/`
GitHub Pages address redirects to the Fillday domain.

Keep `app-ads.txt` intact when changing this portfolio. Check all four detail
links and the mobile layout before publishing to `main`.
