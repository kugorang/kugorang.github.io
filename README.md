# kugorang apps and games

This is the static portfolio at <https://kugorang.github.io/>. GitHub Pages
publishes the root of `main`; no build step or external assets are required.

| Page | Content source |
| --- | --- |
| `/` | Short introductions to Fillday, Moonjunk Workshop, Facet Sudoku, and Oseonro |

Each app owns its detailed site. Fillday publishes from `kugorang/Fillday` at
<https://fillday.kugora.ng/>. Moonjunk Workshop publishes the reviewed `site/`
files from `kugorang/moonjunk-workshop`'s `gh-pages` branch at
<https://moonjunk.kugora.ng/>. Facet Sudoku and Oseonro publish from the
`gh-pages` branches of `kugorang/Sudoku` and `kugorang/oseonro` at
<https://kugorang.github.io/Sudoku/> and
<https://kugorang.github.io/oseonro/>. The portfolio holds only summaries and
links. The legacy `/Fillday/` GitHub Pages address redirects to the Fillday
domain through Fillday's own Pages configuration.

Keep `app-ads.txt` intact when changing this portfolio. Check all four detail
links and the mobile layout before publishing to `main`.
